The useful part

A loop with guardrails.

Freeway makes the safe path the normal one: plan without side effects, approve writes, verify before calling it done.

Plan

Read-only by default.

Ask for the approach first. Plan reads the workspace, names the files and checks, and changes nothing.

Only Build can write.
Build

Approval before action.

Writes, commands and GitHub actions stop at an Allow / Deny card. Auto-approve is opt-in, global and Build-only.

Stop cancels the turn.
Preview

A sandbox, not a deploy.

Open the current chat’s files in a private preview. Bundler and server pages explain what they need instead of faking it.

Credential files are refused.
Secrets

Keys stay out of chat.

Keep provider keys in the Secrets rail. It lists names and hints, never the value, and keeps keys out of the workspace.

Deleting a secret does not revoke it.
